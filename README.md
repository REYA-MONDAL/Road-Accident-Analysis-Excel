# 🚗 Road Accident Analysis – Excel Dashboard

## 📌 Project Overview

This project focuses on analyzing road accident data using **Microsoft Excel** to identify accident trends, patterns, and key insights.

The raw data was cleaned and transformed using **Power Query**, followed by analysis using **Excel formulas, Pivot Tables, Pivot Charts, and dashboard visualizations**.

The objective is to convert raw accident data into an easy-to-understand interactive dashboard that can support data-driven decision-making.

---

## 🎯 Problem Statement

Road accident datasets contain a large number of records and multiple attributes, making it difficult to identify important trends and patterns from raw data.

The goal of this project is to analyze road accident data and develop an **interactive Excel dashboard** that provides a clear view of accident-related metrics and helps users understand accident patterns.
